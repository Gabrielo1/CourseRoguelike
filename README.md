# Action Roguelike - Unreal Engine C++ Project

An action-oriented roguelike game developed in **Unreal Engine 5** using **C++** and **Blueprints**. This project serves as a practical refinement of my Unreal Engine expertise, focusing on building scalable gameplay systems, robust C++ architecture, and efficient game mechanics through advanced patterns.

---

## 🛠️ Key Technical Features & Systems

- **Custom Gameplay Framework:** Architecture built around extensible C++ base classes for actors, characters, and game modes.
- **Object Interaction System:** Interface-driven interaction model allowing flexible player-to-world engagement.

---

## 💻 Tech Stack & Tools

- **Engine:** Unreal Engine 5 (C++ & Blueprints)
- **IDE:** Visual Studio 2022
- **Version Control:** Git / GitHub
